## Intent

A short silent showcase for the TimberLive README and repo page. Lead with the 3D and 2D map views, then the advisor and the Windows app. Calm, product-like, dark UI to match the app.

## Assets

- assets/map3d-orbit-full.mp4 — full 360° orbit of Foreman's 3D map; the 3D scene.
- assets/map3d-orbit-colony.mp4, assets/map3d-height-cut.mp4 — close orbit and height slicer; the split scene.
- assets/map2d-*.png — the four 2D layers; the 2D grid scene.
- assets/foreman-overview.png, assets/foreman-water.png — Foreman UI; the advisor scene.
- assets/app-home.png, app-connect.png, app-stream.png — the app (personal paths already pixelated); the app scene.
- assets/game-colony.jpg, assets/game-river.jpg — real in-game shots from the streams; the game scene.
- assets/icon.png — app icon; title and end card.

## Notes

- Silent by choice (README autoplay is muted); no music or voice.
- No personal paths, names or channel ids on screen.
- "Your AI", not "Claude" only: the app targets any frontier model.
