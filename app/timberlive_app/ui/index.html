Get ready to play

Your AI plays Timberborn with the tools this app ships. Work down the list once; after that just open the app, start the game and point your AI at the workspace.

    Services (run while this window is open)

    Advisor not running

    Foreman watches the game and checks every rule for your AI.

    Connect your AI

    The app doesn't play: your AI does, with two tool servers it starts itself. timberlive observes and acts in the game; foreman is a read-only advisor (keep this window open for it). The workspace folder holds the playbook (AGENTS.md), the knowledge notes and the harness scripts.

    Claude Code

    Best experience: Claude Code can run the harness scripts (watch.py, map surveys, the opening planner) as well as the tools.

    Workspace:

    Claude Desktop

    Adds both tool servers to Claude Desktop. It can play with the tools, but can't run the harness scripts.

    Config:

    Any other MCP client

    Paste this into your client's MCP settings (Cursor, Codex, Gemini CLI, Continue, ...). For a client that can run shell commands, also open the workspace folder and tell it to read AGENTS.md.
